# 👑 Overview

**Mr & Miss Maboneng** is a modern event website created to showcase one of Johannesburg's most exciting pageant experiences. The platform presents contestants, event highlights, schedules, sponsors, and ticket information through an elegant, editorial-inspired interface.

Built with modern frontend technologies, the project emphasizes visual storytelling, smooth user interactions, and responsive design to create an engaging experience for visitors across all devices.
