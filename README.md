This repository contains a standalone static HTML site for **Mr & Miss Maboneng**.

## What’s included
- `mr-miss-maboneng.html` – the main page (all CSS + JS are embedded in the file)
- `maboneng.logo.jpeg` – site logo
- `WhatsApp Image*.jpeg` – contestant images used in the Archive flip cards
- `TODO.md` – task checklist (kept for reference)

## How to run locally
1. Open `mr-miss-maboneng.html` in a browser.
2. Ensure the image files are in the **same folder** as the HTML (this repo keeps them together).


## GitHub Pages (recommended)
If you want the site to be live at `https://<username>.github.io/<repo>/`:
1. Go to the repository on GitHub
2. **Settings → Pages**
3. Select a source:
   - Branch: `main` (or `master` if you keep that)
   - Folder: `/ (root)`
4. Save.

## Deploy considerations
- This project uses **local image filenames** referenced directly by the HTML/JS.
